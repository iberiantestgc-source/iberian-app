# IBERIAN App v1.0

App móvil Expo (React Native) para IBERIAN.

## Pantallas

- Auth: Login, Registro
- Tabs: Home, Estudiar, Stats, Ranking, Perfil
- Test: responder + feedback + resultado
- Tutor IA, Notificaciones, Logros, Ajustes

## Inicio

```bash
npm install
# EXPO_PUBLIC_API_URL=http://IP_DEL_BACKEND:3000/api/v1
npx expo start
```

## Requisitos

Backend IBERIAN en marcha. En dispositivo físico usa la IP local del PC, no localhost.
